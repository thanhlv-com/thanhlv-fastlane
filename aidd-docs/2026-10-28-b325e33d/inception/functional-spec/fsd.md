## 1. Executive Summary & Scope

### 1.1 Project Objective
Ensure that standalone desktop application builds (macOS DMG, Windows EXE, Linux AppImage) generated by `thanhlv-fastlane` accurately reflect the target application version defined in `apps.json` or supplied via CI/CD workflow dispatch parameters (`version`, `build_number`).

### 1.2 System Context & Ecosystem
The orchestration system acts as the build master for target applications stored in `.workspace_code/<app-key>`. During execution, Fastlane prepares the workspace, injects resolved versioning parameters into application manifest files (`package.json`), and executes the underlying packaging engine (`electron-builder`).

### 1.3 Scope Boundaries

#### 1.3.1 In-Scope Functional Modules
- **Version Mutation Helper**: Ruby helper to mutate `package.json` in place before Electron packaging.
- **Fastlane Standalone Lanes (`standalone.rb`)**: Updates to `mac_build`, `win_build`, and `linux_build` to call the version mutation helper and pass `--extraMetadata.version` to `electron-builder`.
- **Target Electron App (`web-clone`)**: Refactoring `src/main/menu.ts` to utilize `app.getVersion()` dynamically.
- **Workflow Verification (`build-standalone-fastlane.yml`)**: Verification that blank versions resolve from `apps.json` and explicit parameters override defaults.

#### 1.3.2 Out-of-Scope (Non-Goals)
- Modifying `pubspec.yaml` for Flutter applications (Flutter CLI's `--build-name` is retained).
- Automatic git tagging or committing inside downstream target app repositories during build.
- Altering mobile distribution lanes (`deploy-ios-fastlane.yml`, `deploy-aos-fastlane.yml`).

## 2. Feature Specifications

### 2.1 Feature: Automated Electron Version Synchronization

#### Preconditions
- Target application is an Electron application (`is_electron_app? == true`).
- `workspace_dir` contains a valid, readable, and writable `package.json`.
- `version_name` has been resolved by `resolve_version_and_build_number(app_info, options)`.

#### Functional Flow (Happy Path)
1. Fastlane identifies `app_info["framework"] == "electron"` or detects `package.json` without `pubspec.yaml`.
2. Fastlane reads `package.json` from `workspace_dir`.
3. If `version_name` is present and non-empty:
   - Sets `package_json["version"] = version_name`.
   - Serializes formatted JSON back to `package.json`.
   - Outputs: `UI.success("📝 Đã cập nhật version: #{version_name} vào #{package_json_path}")`.
4. Fastlane prepares the build command:
   - When running scripts (e.g., `npm run build:mac`), appends `-- -c.extraMetadata.version=#{version_name}` or sets environment variables as appropriate.
5. `electron-builder` packages the application with version `version_name`.
6. Output artifacts are generated with matching version names (e.g., `web-clone-1.0.1.dmg`).

#### Exception Path
- **Invalid JSON in `package.json`**:
  - Fastlane catches JSON parse errors, logs `UI.error("⚠️ Không thể parse package.json: #{e.message}")`, and falls back to passing CLI parameters without crashing the build.

### 2.2 Feature: Target Application Dynamic About Dialog

#### Preconditions
- Application is launched on macOS, Windows, or Linux.
- User opens the system menu and clicks "Giới thiệu Web Clone" (About Web Clone).

#### Functional Flow
1. Electron runtime initializes `app.setAboutPanelOptions(...)` in `src/main/menu.ts`.
2. Runtime fetches `app.getVersion()`.
3. `applicationVersion` is populated with `app.getVersion()`.
4. `version` is populated with `app.getVersion()`.
5. The About dialog displays the dynamic version without any hardcoded text.

## 3. Data Dictionary: Parameters & Manifest Schema

| Field Name | Type | Source | Default / Fallback | Validation Rule |
|---|---|---|---|---|
| `version` (workflow) | String | Workflow Input | `""` (Empty string) | Valid SemVer format (e.g., `1.0.1`, `2.0.0-beta`) |
| `build_number` (workflow) | String | Workflow Input | Unix epoch timestamp (`Time.now.to_i`) | Numeric string |
| `version` (`apps.json`) | String | `fastlane/apps.json` | None (Mandatory per app) | Valid SemVer format |
| `version` (`package.json`)| String | Target workspace | Mutated by Fastlane | Must match resolved `version_name` |
