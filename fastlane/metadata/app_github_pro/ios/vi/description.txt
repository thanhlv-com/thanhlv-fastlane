GitPro là ứng dụng di động cao cấp dành cho lập trình viên và kỹ sư phần mềm, mang lại trải nghiệm quản lý mã nguồn và điều hành dự án GitHub toàn diện ngay trên điện thoại.

Được xây dựng với kiến trúc tối ưu hiệu năng và hệ thống Smart Cache 2 tầng, GitPro mang đến tốc độ phản hồi tức thì 0ms, hỗ trợ đầy đủ các tính năng nâng cao mà lập trình viên chuyên nghiệp cần mỗi ngày.

CÁC TÍNH NĂNG NỔI BẬT:

1. QUẢN LÝ REPOSITORY & XEM CODE CHUYÊN SÂU
• Duyệt cây thư mục Git (Git Tree) với Breadcrumb điều hướng đa tầng mượt mà.
• Trình xem mã nguồn hỗ trợ tô màu cú pháp (Syntax Highlighting) cho hơn 100+ ngôn ngữ lập trình.
• Xem lịch sử Commits, chi tiết từng Commit và Git Blame chính xác theo từng dòng code.

2. REVIEW CODE & QUẢN LÝ PULL REQUESTS / ISSUES
• Giao diện chi tiết 4 tab chuyên sâu: Conversation, Commits, Checks, Files Changed.
• Trình xem so sánh mã nguồn (Git Diff Viewer) trực quan, hỗ trợ chế độ Split & Unified Diff.
• Thao tác Review chuyên nghiệp: Bình luận nội dòng (Inline comments), duyệt (Approve), yêu cầu chỉnh sửa (Request Changes).
• Thực hiện Merge PR 1 chạm: Merge commit, Squash and merge, Rebase and merge.
• Quản lý Milestones, Labels, Assignees và Reviewers linh hoạt.

3. GIÁM SÁT CI/CD (GITHUB ACTIONS)
• Theo dõi trạng thái Workflow Runs theo thời gian thực.
• Kích hoạt chạy thủ công (workflow_dispatch) với form nhập tham số động.
• Xem trực tiếp và tải Log chi tiết của từng Step trong Job để gỡ lỗi nhanh chóng.

4. TRÌNH SOẠN THẢO CODE & COMMIT TRỰC TIẾP
• Sửa đổi code trực tiếp trên điện thoại với số dòng (gutter) và thanh phím tắt lập trình nhanh.
• Tự động tạo Commit trực tiếp vào nhánh hoặc mở Pull Request mới.

5. HỘP THƯ THÔNG BÁO THÔNG MINH (INBOX)
• Phân loại thông báo thông minh (@mentions, review requests, CI failures).
• Bộ lọc Repository tức thì, hỗ trợ đánh dấu đã đọc hoặc hủy đăng ký nhanh.

6. BẢO MẬT & PHÂN TÍCH (INSIGHTS & SECURITY)
• Trung tâm cảnh báo bảo mật: Dependabot alerts, Secret scanning, CodeQL analysis.
• Biểu đồ lưu lượng truy cập (Traffic Insights, Views/Clones), Pulse và xếp hạng Contributor.

7. ĐA TÀI KHOẢN & GITHUB ENTERPRISE (GHES)
• Đăng nhập an toàn qua OAuth 2.0 PKCE hoặc Personal Access Token (PAT).
• Chuyển đổi mượt mà giữa tài khoản cá nhân, tổ chức công ty và máy chủ tự lưu trữ GitHub Enterprise Server.

8. CÁC CÔNG CỤ MỞ RỘNG
• GitHub Projects v2 (Bảng Kanban kéo thả công việc).
• GitHub Discussions (Hỏi đáp cộng đồng, bình luận phân nhánh, Upvote).
• Gists Hub (Soạn thảo và quản lý Code Snippets đa tệp).
• Contribution Heatmap 52 tuần và hồ sơ lập trình viên tương tác.

BẢO MẬT & QUYỀN RIÊNG TƯ:
GitPro lưu trữ thông tin xác thực an toàn tuyệt đối trong Keychain / Encrypted Storage của thiết bị. Mọi kết nối API được truyền trực tiếp đến GitHub API hoặc máy chủ GHES của bạn, không thông qua máy chủ trung gian thu thập dữ liệu.
